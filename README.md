<div>
  <details>
    <summary>How to install</summary>
    <p>Setup a free Minecraft server <a href="https://www.boxtoplay.com/fr/serveur-minecraft/location-minecraft/serveur-minecraft-gratuit" rel="noopener nofollow ugc">BoxToPlay - Free server</a></p>
    <p>Install the plugin software on your server - <a href="https://papermc.io/" rel="noopener nofollow ugc">PaperMC</a></p>
    <p>Download NoSpearEnchant and place it in your <code>plugins/</code> folder</p>
    <p>Restart your server and enjoy! 🎉</p>
  </details>
</div>

---

<div>
  <h2>✨ Features</h2>
  <ul>
    <li>⚔️ <strong>Block Enchanting</strong>: Prevent all maces from being enchanted via table or anvil</li>
    <li>🧹 <strong>Auto Clear</strong>: Remove all existing enchantments on spears when enabled</li>
    <li>🖥️ <strong>Dynamic Reload</strong>: Changes to config.yml are applied automatically without restarting the server</li>
    <li>👤 <strong>Player Join Scan</strong>: Automatically clears spears in inventory of players joining after plugin start</li>
    <li>📋 <strong>Fully Configurable</strong>: Enable/disable auto-clear via config.yml</li>
    <li>⚡ <strong>Lightweight</strong>: Minimal performance impact</li>
  </ul>
</div>

---

<div>
  <h2>🎮 How it works</h2>
  
  <h3>🔒 Preventing Enchants</h3>
  <ol>
    <li>✅ Players cannot enchant a spear at a table or with an anvil</li>
    <li>✅ Any enchantments applied are automatically removed</li>
    <li>🔄 Works instantly for all online players</li>
  </ol>

  <h3>🧹 Clearing Existing Enchants</h3>
  <ol>
    <li>✅ Automatically clears enchantments from spears in inventories of online players when plugin starts (if enabled)</li>
    <li>✅ Clears spears of players joining later</li>
    <li>⚡ Optional: Can be triggered via config reload or command</li>
  </ol>
</div>

---

<div>
  <h2>⚙️ Configuration</h2>
  <p>Customize behavior in <code>config.yml</code>:</p>
  
  <details>
    <summary><strong>Default Settings</strong></summary>
    <pre><code># Clear existing spears on startup and player join
clear-existing-spear-enchants: true
</code></pre>
  </details>
</div>
